# Connections

设置 → 连接 列出本机所有模型凭据来源。托管 Vetta 账号和自备密钥（BYOK）都是 Connection。

- **已登录**：浏览器授权得到，离开时点「退出登录」，会先向服务器撤销再清本地。
- **已提供**：你粘贴的 API Key，离开时点「移除」。Key 仍在服务商那边，只是这台设备不再用。
- **环境变量 / 命令**：只读，删除变量或命令才会消失。

密钥只存在主进程保险库。设置页、诊断包、备份导出都看不到明文。模型请求经本机 127.0.0.1 relay 转发，运行时拿到的是短时 bearer。

账号数据（checkpoints、evolution、recordings 等）按登录账号分区，未登录时落在 `logged-out/`。切换账号不会混用另一账号的目录。
