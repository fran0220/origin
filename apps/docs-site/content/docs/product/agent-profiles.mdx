---
title: Thread 协作
description: 用独立 Thread 并行做事，而不是组一支常驻团队。
---

<Takeaways>
  <li>协作单元是 Thread：出现在会话列表，可被打开、继续、引用</li>
  <li>人对一条 Thread 说话；Thread 再开 Thread；Thread 内请隔离的 specialist</li>
  <li>自定义智能体是人格，不是持久团队</li>
</Takeaways>

Origin 不再提供常驻「智能体团队」。需要并行、独立审查或另开工作区时，当前对话里的 Agent 会调用 `create_thread` 立刻开出另一条会话，再用 `send_thread_message` / `wait_for_threads` / `find_thread` / `read_thread` 互发消息。

## 三种协作

| 方式 | 用在什么时候 |
| --- | --- |
| 人对 Thread | 你在侧栏打开一条会话，自己说话 |
| Thread 开 Thread | 任务能独立推进、不必一直改同一批文件 |
| Thread 内 specialist | 便宜的只读侦察，例如 `spawn_agent(explorer)` |

`create_thread` 立即返回 id，不等子对话推理结束。默认会要求对方回信；已经要求回信的目标不能再 `wait_for_threads`。消息不带文件。

## 智能体档案

侧栏 **智能体** 仍可创建自定义人格，新会话页也可以选一个档案。选中的是这条 Thread 的人格与能力，不会组成可开会的名册。

## Effort Dial

新会话可选 `low | medium | high | ultra`。首条用户消息后，模型和推理档冻结；换档请开新 Thread。
