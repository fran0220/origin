---
title: Configuration and data paths
description: Locate model, settings, MCP, capability, session, and project configuration while preserving ownership boundaries.
---

In the tables below, `~` means the current system user's home directory. The desktop UI is the preferred configuration entry point; direct file edits are for development, diagnosis, and controlled migration.

## Global paths

| Path | Contents |
| --- | --- |
| `~/.origin/agent/settings.json` | Global Coding Agent settings |
| `~/.origin/agent/models.json` | Custom providers and model overrides |
| `~/.origin/agent/auth.json` | Login, OAuth, or manually configured credentials |
| `~/.origin/agent/mcp.json` | MCP server configuration |
| `~/.origin/agent/sessions/` | Session files organized by safe cwd |
| `~/.origin/abilities.json` | Installed capability index |
| `~/.origin/skills/` | User-level skills |
| `~/.origin/scene/` | User-level scenes |
| `~/.origin/plugins/` | User-level plugins |

Set `ORIGIN_CODING_AGENT_DIR` to override the Agent directory. The host, sidecar, and migration tools must use the same value or sessions and configuration will split across directories.

## Project paths

| Path | Contents |
| --- | --- |
| `<cwd>/AGENTS.md` | Long-lived project instructions automatically loaded by project sessions |
| `<cwd>/.origin/settings.json` | Project overrides for global Agent settings |
| `<cwd>/.origin/skills/` | Project-level skills |
| `<cwd>/.origin/extensions/` | Project-level Coding Agent extensions |

Relative paths in project settings resolve from the directory containing `.origin/settings.json`. Project configuration takes precedence over global configuration.

## Editing and migration rules

1. Prefer the Origin settings page so runtime validation and related state stay synchronized.
2. Close active sessions before manual edits to avoid racing with a writer.
3. Never let two processes write the same session file.
4. Preserve directory structure and file names during migration; do not copy only one session body.
5. Before deleting anything, distinguish original sources, processed results, session history, and artifacts because their retention semantics differ.

<Callout type="info" title="Paths are implementation facts, not cross-version contracts">
  Automation should prefer the public SDK, RPC, or exported capability. Do not depend on an internal directory unless this documentation explicitly promises it.
</Callout>
