title: Thread collaboration
description: Run independent threads in parallel instead of a standing agent team.

<Takeaways>
  <li>The collaboration unit is a Thread: it appears in the session list and can be opened, continued, and cited</li>
  <li>A person talks to a Thread; a Thread starts another Thread; a Thread asks an in-thread specialist</li>
  <li>A custom agent profile is a persona, not a persistent team</li>
</Takeaways>

Origin no longer ships standing agent teams. When work can proceed independently, the current Agent calls `create_thread` and immediately gets another conversation. It then uses `send_thread_message` / `wait_for_threads` / `find_thread` / `read_thread` to coordinate.

## Three collaboration shapes

| Shape | When to use it |
| --- | --- |
| Person to Thread | You open a session in the sidebar and talk |
| Thread starts Thread | The work can proceed without constantly editing the same files |
| In-thread specialist | Cheap read-only reconnaissance such as `spawn_agent(explorer)` |

`create_thread` returns an id immediately and does not wait for the child to finish thinking. By default the child is asked to reply; do not also `wait_for_threads` on a thread you already asked to reply. Messages do not carry files.

## Agent profiles

The **Agents** sidebar still lets you create a custom persona, and the new-session page can pick one. That choice is the persona and capabilities of this Thread, not a roster that can hold a meeting.

## Effort Dial

A new session can pick `low | medium | high | ultra`. After the first user message, the model and thinking level freeze; change effort by starting a new Thread.
