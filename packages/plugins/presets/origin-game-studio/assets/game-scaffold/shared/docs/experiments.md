# Experiments

What was tried and refuted, in order. A refuted attempt written down is worth
more than a passing one that was never in doubt: it is what stops the same
wrong idea being tried a third time, and it is the raw material a later
refinement pass distills into a rule.

One entry per attempt:

```text
## <date> — <what was tried>

Expected: <what should have happened, and by what measurement>
Observed: <what actually happened, with the numbers>
Verdict:  <refuted / held / inconclusive, and why>
```

Write the measurement, not the impression. Where nothing was measured, write
unknown — never zero. A difference inside the noise is inside the noise, not
an improvement.
